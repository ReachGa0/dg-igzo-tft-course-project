# IGZO 单极性标准单元

目标拓扑是双栅 IGZO 有源负载逻辑：负载管的第二栅用于调节等效阈值，驱动网络实现反相、与非和或非。只有完成双栅阈值移动标定后，才能把该拓扑称为已验证有源负载电路。

实施顺序：

1. 电阻负载 INV 只用于模型方向、求解和逻辑功能冒烟。
2. 双栅有源负载 INV 验证输出摆幅、静态功耗、增益和噪声裕量。
3. 扩展为 3-TFT NAND2、3-TFT NOR2。
4. XOR2 使用四个已验证 NAND2 层次实例，共 12 个 IGZO TFT。

所有单元必须记录 `VDD`、负载栅偏压、`Wload/Wdriver`、输出负载和采样门限。

当前 C00 R01 执行前合同固定：驱动管 `D/TG/BG/S=VOUT/VIN/0/0`，负载管 `VDD/V_TOP_LOAD/VDD/VOUT`；DC/瞬态计划案例分别为 18/36，锚点为 `v200_t100_r0125_c1000`。这些只是 E0 合同输入。48 项静态 PASS 状态提交前，本目录不得新增正式 C00 网表，且不能报告任何电路数值。
