## 1. 正式题目

**基于双栅 IGZO TFT 的二维器件模型、紧凑模型与可编程单极性逻辑教学 PDK**

S00、完整 T01/T02 教学模型数值门和全部五组数值 T03 已完成，历史失败继续保留。M00 R02 与 M01 只在冻结 IGZO 教学数值域内受限关闭。M01 正式 R01 39/40 E0/FAIL、R02 40/30/24 路线分歧及根因历史不可改写；`M01_OPEN_SOURCE_DEVICE_DC_R03` 42/30/24 E3/E2/E3 满足冻结四项验收，因此 M01 记录 `M01_TEACHING_MODEL_ONLY_PASS`。C00 R01/R02/R03 历史冻结；R04 静态合同唯一 50/50 E3 后，四进程 runner 唯一返回 33/36 E0/FAIL。输出轴和完整表通过，但冻结锚点只有约 0.0912 V VOH、约 0.884 最大增益且无瞬态输出 crossing，因此 C00 与下游继续关闭。

本次课程提交的有效范围见 [SUBMISSION_ARCHITECTURE.md](SUBMISSION_ARCHITECTURE.md)：主线止于 C00 的正式负结果和 HTML/PDF/PPT 交付。C01--C03、版图、PEX 与 HZO 不属于本次提交，不在封面、摘要、结论或答辩中作为待完成工作承诺。

## 2. 为什么这个题目仍然成立

项目核心没有改变：围绕高难度“双栅氧化物 TFT 模型”，建立器件到电路再到版图验证的参数链。范围收敛为单材料 IGZO 后：

1. 二维 TCAD、紧凑模型和参数提取更加集中。
2. 不需要同时解决两类材料的数据与模型不一致。
3. 电路改为双栅 IGZO 有源负载单极性逻辑，第二栅的阈值调节能直接连接器件研究与电路设计。
4. 本次只交付已完成的器件、模型、C00 评估和报告全流程。
5. 标准单元、版图、PEX 与 HZO 已从提交范围移出。

## 4. 固定逻辑拓扑

使用 n 型双栅 IGZO 有源负载：负载管由第二栅调节等效阈值，驱动网络负责下拉。它是有比例逻辑，必须报告低电平静态功耗、输出摆幅和负载/驱动尺寸比。

| 单元 | 层次结构 | TFT 数 |
|---|---|---:|
| INV | 负载 + 驱动 | 2 |
| NAND2 | 负载 + 2 个串联驱动 | 3 |
| NOR2 | 负载 + 2 个并联驱动 | 3 |
| XOR2 | 4 个 NAND2 | 12 |
| RING5 | 5 个 INV | 10 |
| FULL_ADDER | 2 XOR2 + 3 NAND2 | 33 |

若有源负载暂不收敛，只能用理想电阻负载做求解/Boolean 冒烟，不能据此报告 PDK、面积或真实功耗。

## 5. 数据事实

基础工艺：

```text
Si substrate / 300 nm thermal SiO2
50 nm Al bottom gate
30 nm Al2O3 physical gate dielectric
24 nm IGZO active layer
50 nm Ti source/drain and interconnect
```

课程尺寸与后续参数口径：

```text
W/L = 60/10 um
effective TOX = 10 nm
dielectric k = 6.8
mobility approximately 35.5 cm2/(V s)
VTH = 0.21 V
```

早期论文文字还给出另一组 IGZO 数据：迁移率 10.05 cm2/(V s)、SS 0.86 V/dec、Ion/Ioff 约 5.28e5、VTH 5.00 V。两组数据来源/批次不同，不能拼成同一器件模型。

30 nm 是工艺物理厚度，10 nm 是当前 SPICE 有效 TOX 口径，必须分栏记录。

- V3 只把全部器件共同网格扩展为 `-0.5~1.8 V/0.05 V`，其他密度点、方程、提取和验收阈值不变。24/24 E3 合同冻结 8 器件、456 次计划 DC、376 个计划点、8 状态和 48 VTK；合同检查没有运行 DEVSIM。
- V3 随后按冻结合同完成 8 器件、456 次全部收敛 DC、376 个 transfer 点、8 状态和 48 VTK；墙钟 36.669 s，最大端口相对不平衡 6.01e-9，运行器 17/17 PASS，独立检查 16/16 PASS。两个零控制对 T02-C 的共同点曲线和提取差异均为 0。
- NTA 的 VTH/SS 代理随密度严格增加、gm 代理严格下降；NGA 的 VTH 代理增加、gm 代理下降，但 SS 代理从 137.594 轻微降到 132.874 mV/dec。方向假设在合同中只作诊断，后者不触发完成失败，也不得被解释为真实深态机制。
- 随 DIT 增加，本教学方程中 VTH 代理为 0.263857/0.283583/0.316118/0.338997 V，SS 代理为 137.594/168.657/231.493/292.966 mV/dec，gm 代理递减。最低栅压电流代理递增，受 `Psi_neutral=0 V` 线性化电荷符号影响，不得称为物理 Ioff。
- 两次失败保留在完整证据包中：首次为 DEVSIM mesh 重名；V1 两 decade SS 窗口在零/低 DIT 曲线上不满足预注册 `R2>=0.98`。V2 改用一 decade 固定窗口，没有放宽 R2 门槛。
