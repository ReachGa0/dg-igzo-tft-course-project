# 报告目录

最终报告必须遵守老师要求：提交一个可独立打开的 UTF-8 HTML，CSS 和全部图片均嵌入，不能依赖网络、本地绝对路径或同目录图片。

```text
report/
|-- src/实验报告_草稿.xhtml  # 结构化工作稿，严格包含 12 个主章节
|-- assets/                  # 构建前的本地图，最终会转为 Base64
|-- evidence_matrix.csv      # 每条结论到数据/脚本/命令的索引
`-- final/实验报告.html      # 最终单文件，生成后才存在
```

只检查章节结构：

```bash
make report-check
```

正式构建：

```bash
make report
```

正式构建会拒绝未解决的 `[待填写...]`、缺失图片、空 `alt`、外部图片、外部 CSS 和外部脚本。报告还必须包含数据来源、重建命令、误差、故障注入、证据边界与 AI 使用声明。
