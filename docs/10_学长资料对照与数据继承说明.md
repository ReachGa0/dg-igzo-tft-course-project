## 1. 先说结论

学长资料对本项目有三个直接价值：

1. **报告结构参考**：采用“背景与问题 -> 方法 -> 结果 -> 定量讨论 -> 总结”的叙事顺序。
2. **二维 TCAD 操作参考**：`VisualTCAD_Inverter.pptx` 展示了结构、边界、器件符号、电路扫描和 VTC 的完整操作链。
3. **交叉检查数据**：两份 Excel 可验证我们的 Office 数据导入、清洗和作图流程。

但它们没有提供一套条件完整、可直接用于本项目精确拟合的双栅 IGZO 原始测量数据。

### 3.1 IGZO TCAD 参考曲线

规范字段：

| 字段 | 含义 |
|---|---|
| `source_file/source_sheet/source_row` | 可回到 Excel 的位置 |
| `v_gate_v` | 原表 Gate 电压，单位 V |
| `drain_current_a` | 原表 Drain 电流，单位 A |
| `abs_drain_current_a` | 对数图使用的绝对值 |
| `quality_flag` | 求解器地板、非正电流或强非单调点提示 |
| `condition_status` | 缺少哪些实验/仿真条件 |

低电流区存在接近数值地板和非单调点。正确做法是保留原值并标记，不能为了画出平滑曲线偷偷删除。

### 3.2 两组 VTC 参考曲线

规范字段保留两列为 `vout_case_1_v`、`vout_case_2_v`，不猜测它们分别是什么工况。只有从学长处或原工程恢复电路、VDD、器件参数和扫描设置后，才可以重命名。

## 4. 报告结构借鉴什么

学长 PPT 的可取之处是每一张结果图配有：

1. 器件尺寸和偏压；
2. 横纵轴物理量；
3. 提取值；
4. 物理解释；
5. 与其他方案的比较。

本项目要进一步补上：

- 数据和参数来源；
- 输入文件与重建命令；
- 拟合集与验证集；
- 网格或数值收敛；
- 误差指标；
- 失败案例；
- 证据等级；
- AI 使用与人工检查。

## 5. 从学长报告吸取的反例

### 5.1 不能只放软件截图

截图能证明界面曾显示某个结果，但不能自动复算。正文曲线要从 CSV 重画，截图只放在“软件设置/操作说明”中。

### 5.2 不能同时改变多个变量后归因

若同时改变电阻和电压，输出变化无法归因到单一变量。高难度项目要求的“五组参数”是五类受控实验，不是一次把五个参数全改掉。

### 5.3 不能省略条件

一列 `Vin/Vout` 没有 VDD 和电路，或一列 `Id/Vg` 没有 VDS 和 W/L，都不能支撑严格的器件结论。元数据缺失本身要写入质量报告。

## 6. 报告中建议怎样表述

可以写：

> 学长 VisualTCAD 工程用于确定二维器件仿真的操作与报告组织方式；学长 Excel 数据用于验证数据导入和质量标记流程。由于原文件缺少完整偏压、几何和模型元数据，这些数据仅作为参考集，未用于声明本项目模型精度。

不能写：

> 本项目复现了学长的双栅 IGZO 实验，精度很高。

因为目前没有对应原工程、完整条件和误差计算支持这句话。
