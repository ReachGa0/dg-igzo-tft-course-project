# 双栅 IGZO 项目知识点与实验设计原理

> 目的：讲清楚每一步为什么做、改变什么、固定什么、看什么图、什么结果才算有效。  
> 当前状态：总体架构已冻结，除既有二维静电基准外，新的领域实验尚未开始。

## 0. 一句话理解项目

```text
IGZO 数据和工艺
  -> 二维器件内部状态
  -> 端口 I-V 和双栅阈值耦合
  -> 紧凑模型
  -> 双栅 IGZO 有源负载逻辑
  -> 标准单元、环振、全加器
  -> GDS、DRC、几何 LVS
  -> 可选 HZO 可编程顶栅
```

真正的成果不是某一张曲线，而是每一级都能回答：输入来自哪里、中间用了什么模型、输出能证明到什么程度。

## 1. 科研实验的六个组成

每个实验必须写：

| 项目 | 问题 | 本项目例子 |
|---|---|---|
| 研究问题 | 到底想知道什么 | 顶栅偏压是否移动底栅阈值？ |
| 假设 | 预计方向是什么 | 更正的顶栅偏压增强电子沟道 |
| 自变量 | 主动改变什么 | Vtop |
| 因变量 | 记录什么 | VTH、gm、ID、沟道势 |
| 控制变量 | 什么必须不变 | W/L、VDS、温度、陷阱、接触和网格 |
| 判据 | 怎样支持或否定假设 | 趋势单调，关闭顶栅后返回基线 |

一次同时改变五个参数后只能观察相关性，不能证明因果。高难度“五组参数”应当是五类受控实验，不是把五类参数一次全改。

## 2. 证据等级

- `E0`：计划或想法。
- `E1`：论文支持，本项目未复现。
- `E2`：可运行并有自测输出。
- `E3`：有自动验收、故障注入或独立验证。
- `E4`：老师、实验或外部工具确认。

文件存在不代表物理正确；软件显示 PASS 也不等于模型得到实验验证。

## 3. IGZO TFT 怎样工作

### 3.1 基础结构

```text
Ti source/drain and interconnect: 50 nm
IGZO active layer: 24 nm
Al2O3 gate dielectric: 30 nm physical thickness
Al bottom gate: 50 nm
SiO2 on Si substrate: 300 nm
```

底栅通过 Al2O3 电场调节 IGZO 电子浓度。Ti 与有源层形成源漏接触。双栅研究在上方增加教学顶介质和顶栅，这一层不是原工艺已制造的事实。

### 3.2 电压和电流

```text
VGS = VG - VS
VDS = VD - VS
```

正的有效栅压通常增强 n 型电子沟道。端口、电流方向和源漏参考必须在数据、TCAD 与 SPICE 中一致，否则会出现“曲线有形状但符号全错”。

### 3.3 W/L 和栅电容

长沟道趋势：

```text
Cox = epsilon0 * epsilon_r / tox
ID,linear ~ mu * Cox * (W/L)
ID,sat ~ 0.5 * mu * Cox * (W/L) * (VGS - VTH)^2
```

这些式子用于理解趋势，不是非晶氧化物完整模型。陷阱、接触、偏压依赖迁移率和非理想饱和都会使实际曲线偏离平方律。

本项目课程尺寸：`W/L=60/10 um`。

## 4. 怎样读 Id-Vg 和 Id-Vd

### 4.1 转移曲线 Id-Vg

固定 VDS，扫描 VGS。至少画两张：

1. 线性纵轴：看开态电流、gm 和强导通区。
2. 对数纵轴：看关态、SS、漏电和开关比。

只画线性轴会把关态压在零附近；只画对数轴会弱化开态绝对误差。

### 4.2 阈值 VTH

VTH 依赖提取方法。定电流法、gm 外推和 `sqrt(ID)` 外推会得到不同数值。报告必须写提取方法、VDS、W/L 和电流是否归一化。

### 4.3 亚阈值摆幅 SS

```text
SS = dVGS / d(log10 ID)
```

SS 越小，开关越陡。陷阱增加或栅控变弱通常使 SS 变差，但不能只用一条曲线唯一分离体陷阱和界面陷阱。

### 4.4 输出曲线 Id-Vd

固定多个 VGS，扫描 VDS。重点检查：

- 原点附近斜率和接触限制；
- 是否出现合理饱和；
- 高 VDS 输出电导；
- 不同 VGS 曲线是否顺序正确；
- 正反向或源漏互换时是否异常。

## 5. 当前数据口径

### 5.1 早期论文文字

```text
mobility = 10.05 cm2/(V s)
SS = 0.86 V/dec
Ion/Ioff approximately 5.28e5
VTH = 5.00 V
VDS = 1 V
```

### 5.2 后续课程参数

```text
W/L = 60/10 um
mobility approximately 35.5 cm2/(V s)
VTH = 0.21 V
effective TOX = 10 nm
dielectric k = 6.8
```

两组数据不属于同一批次/口径，必须分别编号。30 nm 物理介质厚度与 10 nm 有效 TOX 也必须分开。没有原始曲线时，后续参数只能称为课程目标，不称为全局拟合。

## 6. 为什么二维 TCAD 要分层

完整 TFT 同时包含：

1. Poisson 方程；
2. 电子连续性；
3. 漂移扩散；
4. 态密度和陷阱占据；
5. 接触注入；
6. 迁移率、复合和温度模型。

如果一次全加，失败时无法定位。因此固定顺序：

```text
T00 静电 -> T01 单栅电流 -> T02 双栅 -> T03 陷阱/接触/几何/温度
```

### 6.1 T00 静电能证明什么

无自由电荷时：

```text
div(epsilon * grad(phi)) = 0
```

它验证几何、边界、电势方向和网格。既有对称结构中上下栅耦合各为 0.5 V/V，粗细网格中心势差为 0 V。

它不能给出 ID、VTH、SS、迁移率、陷阱或接触结论。

### 6.2 T01 漂移扩散

```text
div(epsilon * grad(phi)) = -rho
div(Jn) = q(R-G)
Jn = q*mu*n*E + q*Dn*grad(n)
```

求解顺序应是零偏压平衡、低 VDS、逐步增加 VGS，并用上一偏压点作初值。直接跳到最大偏压导致不收敛，不能证明物理模型错误。

最低输出：Id-Vg、Id-Vd、三种工作状态的电势/电子浓度/电流密度、网格比较、电流守恒和失败点。

## 7. 双栅耦合

简化等效形式：

```text
Veff = alpha_bottom*Vbottom + alpha_top*Vtop
```

`alpha` 不是任意拟合旋钮。理想电容近似中与上下介质电容有关；有沟道电荷和陷阱后还会随工作点变化。

双栅实验必须分别：

- 固定顶栅，扫描底栅；
- 固定底栅，扫描顶栅；
- 提取 Delta VTH 对另一栅偏压的斜率；
- 比较二维沟道势和电子浓度；
- 关闭顶栅耦合检查是否返回单栅基线。

没有双栅实测时只能说“参数化敏感性”或“模型预测”。

## 8. 五组参数为什么这样选

| 组 | 改变 | 主要观察 | 用来区分什么 |
|---|---|---|---|
| P1 双栅 | Vtop、Vbottom、电容比 | Delta VTH、gm、沟道势 | 栅耦合强弱 |
| P2 陷阱 | 带尾态、深态、Dit | SS、VTH、Ioff | 栅控与缺陷 |
| P3 接触 | Rc 或势垒 | 线性斜率、Ion、Id-Vd | 接触与沟道迁移率 |
| P4 几何/介质 | L、tch、tox、k | Ion、场和短沟道趋势 | 尺寸与材料参数 |
| P5 温度 | 至少三个温度 | VTH、SS、Ion、漏电 | 热激活与模型外推 |

每组先单因素三点以上，再做必要的二维交互。所有对比使用统一坐标范围、提取方法和偏压条件。

## 9. TCAD 怎样传给紧凑模型

不是把 TCAD 每个内部参数同名抄入 SPICE，而是传递可观测约束：

| 器件结果 | 紧凑模型约束 |
|---|---|
| 低 VDS Id-Vg | VTH、gm、电流尺度、SS |
| 多 VGS Id-Vd | 线性区、饱和、输出电导和接触 |
| 双栅曲线族 | 耦合系数和阈值偏移 |
| 几何电容/瞬态 | Cgs、Cgd 和负载 |
| 温度曲线 | 温度系数和适用范围 |

至少留一条不同 VDS、尺寸或温度曲线作 holdout。所有曲线都用于调参，只能证明重现训练集。

## 10. 两条 SPICE 路线

### 10.1 AIM-Spice Level 15

用于响应老师指定的 amorphous-silicon TFT 模型级别。报告需说明 Level 15 与 HSPICE Level 61 的对应关系、参数单位和软件语法差异。

### 10.2 ngspice 行为模型

用于开源批量仿真和自动回归。它可匹配相同端口目标，但不能声称内部方程等价于 Level 15。

两条路线共用数据、偏压和误差指标，输出差异表。

## 11. 为什么采用 IGZO 有源负载逻辑

只有 n 型器件时，上拉不能沿用理想互补网络。本项目用双栅 IGZO 负载管：第二栅调节负载的等效阈值，驱动网络负责下拉。

这使双栅器件研究有直接电路意义，但代价是：

- 输出低时可能有静态电流；
- VOH/VOL 和翻转点依赖负载/驱动比；
- 逻辑是有比例的；
- 第二栅模型不可靠时，电路结论也不可靠。

## 12. 反相器必须先验证什么

### 12.1 DC

从 VTC 提取：

- VOH、VOL；
- 翻转点 VM；
- 最大增益；
- VIL、VIH；
- NML、NMH；
- 低输出静态电流。

扫描：负载第二栅偏压、`Wload/Wdriver` 和 VDD。只调到“曲线好看”不够，必须同时报告功耗和摆幅代价。

### 12.2 瞬态

固定输入边沿、负载电容和 50% 门限，报告 tPLH、tPHL、上升/下降时间和平均功耗。输入还没稳定就采样会产生假延迟。

## 13. 基础门、环振和全加器

固定结构：

```text
INV: 2 TFT
NAND2: 3 TFT
NOR2: 3 TFT
XOR2: 4 x NAND2 = 12 TFT
RING5: 5 x INV = 10 TFT
FULL_ADDER: 2 x XOR2 + 3 x NAND2 = 33 TFT
```

### 13.1 NAND/NOR

- NAND：两个驱动串联，只有 A=B=1 时拉低。
- NOR：两个驱动并联，任一输入为 1 即拉低。

串联会减弱下拉，内部节点可能影响延迟。必须逐输入组合验证。

### 13.2 环振

奇数级反相器闭环，近似：

```text
fosc approximately 1/(2*N*tpd), N=5
```

需要启动扰动、稳态周期窗口和周期波动检查。只看到几次摆动不能证明稳定振荡。

### 13.3 全加器

```text
SUM = A xor B xor CIN
COUT = A*B + CIN*(A xor B)
```

采用 `2 XOR2 + 3 NAND2`，验证 8 行真值表和 SUM/COUT 最坏延迟。顶层版图必须保留子单元层次。

## 14. PDK、PCell 和 GDS

PDK 至少包含：

- 层表和层显示；
- 工艺/模型参数边界；
- IGZO 单栅/双栅器件 PCell；
- 标准单元生成器；
- DRC 和 LVS deck；
- 参考网表、端口顺序和验收脚本。

彩色矩形不是器件。PCell 必须有真实有源区、沟道、栅、源漏、互连、开口、PIN 和参数化 W/L。

## 15. DRC 为什么要故障注入

一个空 deck 也可能显示 0 errors。必须故意制造：

- Ti 线宽过小；
- 间距过小；
- 栅未覆盖沟道；
- 开口包围不足。

正确版图 PASS、错误版图 FAIL、修复后再 PASS，才证明规则确实工作。

## 16. LVS 为什么必须从 GDS 提取

合格路径：

```text
GDS geometry
  -> identify IGZO channel and gates
  -> identify source/drain contacts
  -> extract devices and nets
  -> compare with reference SPICE
```

版图生成器顺便输出一份网表，再和自己的源网表比较，不能发现 GDS 中的断路或短路，不算最终 LVS。

故障注入至少包括断路、短路和 PIN 错标。

## 17. HZO 扩展放在哪里

HZO 是顶栅介质/极化扩展，不是 IGZO 沟道替代。分层：

1. 双栅静态电容耦合，无回滞；
2. 准静态极化引起 Delta VTH；
3. 有时域数据后再做 NLS；
4. 唤醒、疲劳、应变和界面只作参数敏感性。

关闭铁电参数后必须回到双栅基线，否则模型接口不一致。

## 18. 每阶段的失败意味着什么

| 现象 | 先检查 | 不能立刻得出的结论 |
|---|---|---|
| T01 不收敛 | 网格、边界、初值、偏压步长和单位 | IGZO 物理模型错误 |
| Id-Vg 太平 | 栅接触、介电常数、陷阱和载流子方程 | 迁移率一定太低 |
| 线性区电流低 | 接触、W/L、迁移率和电流归一化 | 沟道材料性能差 |
| INV 高电平不足 | 负载阈值、第二栅偏压和尺寸比 | 仿真器有问题 |
| 静态功耗高 | 有比例逻辑直流通路 | 数据一定错误 |
| 环振不启动 | 反相器增益、级数、初值和负载 | 模型完全不能用 |
| DRC 0 违例 | deck 是否真正读取目标层 | 版图可流片 |
| LVS 总是 PASS | 是否从 GDS 提取、故障注入是否生效 | 所有连接正确 |

## 20. 当前最重要的边界

- 架构完成不等于实现完成。
- 既有 T00 是无移动电荷静电基准。
- 学长 IGZO 表缺少 VDS、几何和模型设置。
- 有源负载电路尚无当前结果。
- 顶栅和 HZO 不是原始单底栅工艺已制造的事实。
- 报告中任何定量结论必须能回到输入、命令和机器报告。

## 21. 为什么实验顺序不能换

如果全加器错误，原因可能来自器件极性、双栅阈值、负载强度、门拓扑、采样时刻、版图断路或寄生。按器件 -> 模型 -> INV -> 基础门 -> 模块 -> 版图验证的顺序，每一级都能缩小故障范围。这个分层验证过程本身就是课程项目最重要的工程经验。
