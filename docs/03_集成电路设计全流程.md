# 集成电路设计全流程

## 一张图记住全流程

```text
需求/真值表
  -> 器件数据与紧凑模型
  -> 原理图/源 SPICE 网表
  -> 前仿真
  -> 工艺层表 + 设计规则 + PCell
  -> floorplan / placement / routing
  -> GDS/OASIS
  -> DRC
  -> 从 GDS 提取网表
  -> LVS
  -> 寄生提取 PEX
  -> 后仿真
  -> 结果、限制和交付
```

## 1. 需求定义

不先定义输入/输出就开始画版图，最后很容易得到一张“看似像电路”但无法验证的图。

对每个单元先定义：

- 端口名与顺序。
- 真值表/布尔表达式。
- VDD、输入电平、负载电容和输入边沿。
- 功能、延迟、功耗和面积的验收阈值。

## 2. 器件建模

紧凑模型是材料/器件与电路之间的桥梁。对 TFT 至少需要描述：

- 亚阈值漏电。
- 阈值电压。
- 线性区和饱和区电流。
- 迁移率/跨导。
- 输出电导或沟道长度调制。
- 源漏串联电阻。
- 栅源/栅漏与负载电容，否则环振频率没有可信度。

多曲线标定要把数据分成拟合集与验证集，避免只对一条曲线过拟合。

## 3. 原理图和源网表

源网表是设计意图的唯一主源。版图生成器、电路图和测试都应该引用这份网表，避免三份手工副本慢慢分叉。

在源网表中固定：

- 子电路名。
- 端口顺序。
- 器件模型名。
- W/L 和派生器件尺寸。
- 内部网络名。

## 4. 前仿真

前仿真只看原理图网表和人工负载，不包含真实版图互连寄生。

对逻辑单元至少做：

- DC 真值表或 VTC。
- transient 边沿与传播延迟。
- 输出高/低电平。
- 功耗积分，区分静态与动态。
- PVT/参数敏感性，至少包括 VTH、mobility、电容和 VDD。

## 5. PDK 的组成

一个可用的教学 PDK 至少包含：

- 层表：层名、GDS layer/datatype、物理含义、是否为掩膜。
- 显示文件：颜色和默认可见性。
- 参数化器件 PCell。
- 设计规则文档和 DRC deck。
- LVS 器件识别、连通性和模型映射。
- 模型库与角点。
- 可重复的生成、验证和安装脚本。

## 6. Floorplan、放置与布线

### Floorplan

决定单元轮廓、VDD/GND 轨、负载区、驱动区和端口边界。本项目上方放置双栅 IGZO 有源负载，下方放置 IGZO 驱动网络，并预留负载第二栅偏压端口。

### Placement

放置不是随便排列矩形。要尽量：

- 让共用网络的器件靠近。
- 将串联器件按电流路径排列。
- 避免不必要的金属跨越。
- 保持标准单元端口位置一致。

### Routing

本工艺的 Ti 是主金属，Al 底栅位于 Al2O3 下方。Ti 与 Al 只有在 `DIEL_OPEN` 处才导通。因此 Al 可能在远离有源区时用作局部桥接，但这项使用必须得到老师确认并加入 DRC。

## 7. DRC 是什么

DRC（Design Rule Check）回答“这些形状是否满足指定的几何规则”。

常见类型：

- 最小线宽。
- 最小间距。
- 包围/伸出。
- 最小开口。
- 有源区与栅的重叠。
- 沟道长度/宽度。
- 不允许的层重叠。

DRC PASS 不代表电路连接正确，只代表这套规则没发现几何违例。

## 8. LVS 是什么

LVS（Layout Versus Schematic）回答“从版图提取出来的电路是否等价于原理图”。

LVS 需要三部分：

1. 器件识别：哪些形状组成 IGZO TFT，S/D/主栅/第二栅在哪里，W/L 是多少。
2. 连通性：同层相触是否相连，不同层通过什么开口连接。
3. 网表比较：器件类型、数量、参数、网络和端口是否等价。

KLayout 官方文档给出了 `extract_devices`、`connect`、`schematic` 与 `compare` 流程：[KLayout LVS Introduction](https://www.klayout.org/downloads/master/doc-qt5/manual/lvs_intro.html)。

## 9. PEX 和后仿真

PEX（Parasitic Extraction）提取互连电阻、对地电容、耦合电容等。前仿真中的环振频率对人工负载电容敏感，真实版图寄生往往会降低频率并改变边沿。

本项目时间有限，PEX 分三档：

- P0：人工固定负载，只能称前仿真。
- P1：按线长、线宽和重叠面积计算简化 RC，称教学寄生估算。
- P2：经校准的场求解/工艺 RC deck，才能称可定量后仿真。

本课程至少目标是 P1，不伪装 P2。
