# 验证与验收标准

## 验收原则

1. 每个 PASS 都必须有程序可读报告。
2. 每个工具必须至少有一个预期 FAIL 测试，证明它不是无条件输出 PASS。
3. 原始输出与解析摘要分开保存。
4. 重建命令从项目根目录运行。

## A. 器件模型

| 检查 | 最低验收 | 冲高分验收 |
|---|---|---|
| 数据完整性 | 单位、W/L、VDS/VGS 扫描条件齐全 | 原始点哈希与数据版本化 |
| Id-Vg | 线性/对数坐标均叠图 | 拟合集和验证集分开 |
| Id-Vd | 多个 VGS 曲线 | 线性区、饱和区分区误差 |
| 特征参数 | VTH、SS、Ion/Ioff、mobility | 置信区间与参数相关性 |
| 数值稳定 | DC/transient 无不收敛 | 广偏压、温度/参数边界扫描 |

不在数据充分前硬规定“RMSE < x%”。先报告实际误差分布，再与老师确认可接受阈值。

## A0. 二维 TCAD

### 静电基准 T00

- 结构、坐标单位、区域、接触和界面可由脚本重建。
- 至少粗/细两档网格，比较同一偏压下的中心沟道电势。
- 上/下栅扫描方向正确，结果无 NaN/Inf。
- 保存 VTK、节点 CSV、耦合 CSV、PNG、运行输出和 JSON 摘要。
- 报告明确写“无移动电荷、无漏电流”，不得将其作为 Id-Vg 结果。

当前 T00 验收结果：粗/细网格中心势均为 `0.5 V`，差值 `0 V`；对称介质下上下栅耦合均为 `0.5 V/V`。

### 漂移扩散 T01/T02

| 检查 | 最低验收 |
|---|---|
| 求解顺序 | 平衡态 -> 小 VDS -> 分步 VGS/VDS，不从零初值直接跳最大偏压 |
| 网格 | 至少两档，对 VTH/SS/Ion 或明确替代指标做定量比较 |
| 守恒 | 源漏端口电流差或连续性残差在声明阈值内 |
| 内部状态 | 关态、阈值附近、开态的电势、电子浓度和电流密度 |
| 参数来源 | 材料、陷阱、接触和温度均标来源类型 |
| 失败记录 | 不收敛点、步长和修复方法保留 |

当前 T01-D-A 验收结果：固定 T01-C fine 的横向/体区网格与全部物理输入，仅把界面窗口按 1x/2x/4x/8x 加密；4x/8x 在 `VDS=0.01 V`、`VGS=0.5/1.0 V` 的最大电流差为 `0.01639%`，中心沟道势差为 `0.03265 mV`，低于预先冻结的 `5%/1 mV` 门。该 PASS 只打开 T01-D-B Id-Vd，不替代完整 T01 验收。

当前 T01-D-B 验收结果：`interface_4x` 的 4 条正式曲线和 `interface_8x` 的 2 条高栅压复核曲线均从独立零偏压平衡态开始，共完成 65 次 DC、30 个正式点；全部求解收敛，曲线随 VDS 单调不减，非零 VDS 最大源漏相对不平衡为 `7.28e-14`，4x/8x 最大电流差为 `0.01639%`、中心势差为 `0.03289 mV`，独立 16 项检查 PASS。VDS=0 使用绝对电流阈值，不对舍入级零电流计算相对守恒；该 PASS 只打开 T01-D-C，不验证连续输出行为、饱和机理、参数提取或实验精度。

当前 T01-D-C 验收结果：`interface_4x/interface_8x` 各完成 VDS=0.01 V 下的 51 点定向 VGS 网格，两档共 120 次 DC、102 个正式点全部收敛，最大端口相对不平衡为 `6.76e-8`，电流随 VGS 单调增加。关态代理、课程目标附近代理和开态代理均保存电势、电子浓度、三角形三节点电流密度矢量和 VTK；4x 数值代理 VTH/SS/场效应迁移率为 `0.217535 V`、`59.6081 mV/dec`、`19.1739 cm2/(V*s)`，4x/8x 差分别为 `0.017 mV`、`2.49e-9` 相对值和 `0.0265%`，独立 17 项检查 PASS。该 PASS 关闭冻结教学模型的 T01 数值门；这些代理不是实测参数，约 17.42 decade 数值跨度不是物理 Ion/Ioff。

高难度参数分析固定至少五组：双栅、陷阱、接触、几何/介质、温度。每组必须是受控扫描，不允许一次同时改多个变量后归因。

## B. 标准单元前仿真

| 单元 | 器件数 | 功能验收 | 模拟验收 |
|---|---:|---|---|
| INV | 2 | 0->1，1->0 | VTC、VOH/VOL、VM、tpHL/tpLH |
| NAND2 | 4 | 4/4 真值表 | 所有输入翻转路径 |
| NOR2 | 4 | 4/4 真值表 | 所有输入翻转路径 |
| XOR2 | 12 | 4/4 真值表 | A/B 分别翻转，检查毛刺 |

数字判决建议：`LOW <= 0.1*VDD`，`HIGH >= 0.9*VDD`。若模型无法满足，必须报告实际噪声容限而不是放宽阈值隐藏问题。

## C. 版图几何

- 单元层次中的 TFT 实例数等于规格。
- 每个 TFT 都有唯一器件 ID、材料、W/L 和 S/D/G 端子。
- 每个顶层端口在 PIN 层有形状和文本。
- 不存在占位子单元、空实例、边界外图形或浮空金属。
- 输出 GDS 读回后的层数、单元数、实例数和尺寸与 manifest 一致。

## D. DRC

### PASS 条件

- 指定 top cell 的违例数为 0。
- DRC deck 版本、GDS 哈希和工具版本写入报告。
- 报告包含所有已定义规则 ID，不是空 deck。

### 故障注入

1. 将一根 Ti 线缩小到最小线宽以下，预期 `T1` FAIL。
2. 将两根 Ti 线移到间距以下，预期 spacing FAIL。
3. 减小 `DIEL_OPEN` 包围，预期 enclosure FAIL。
4. 让 Ti 覆盖沟道标记，预期 channel-overlap FAIL。

## E. LVS

### PASS 条件

- extracted/reference 顶层电路配对。
- 顶层端口名、数量和连接一致。
- IGZO 有源负载/驱动器件总数、主栅和第二栅连接一致。
- W/L 在设定容差内一致。
- 无未配对网络、器件或子电路。

### 故障注入

1. 断开一根连线：预期抽取网络数增加并 FAIL。
2. 用金属短接两个网络：预期抽取网络合并并 FAIL。
3. 删除一个 TFT：预期器件数不匹配。
4. 改变一个 TFT 的 W：预期参数不匹配。
5. 交换 SUM/COUT 标签：预期端口网络不匹配。

## F. 5 级环振

- 级数为 5，由 5 个已验证 INV 实例组成。
- 稳态后至少检测 10 个同方向阈值交叉。
- 对后半段周期求平均和标准差，不用第一个启动周期代表频率。
- 报告 `fosc`、周期变异、`tpd = 1/(2*N*fosc)` 和平均供电功率。
- 前仿真、简化寄生后仿真分开标注。

## G. 1 位全加器

- 结构是 `2 XOR2 + 3 NAND2`，共 36 TFT。
- 8 组 A/B/CIN 全部 PASS。
- transient 采样点距离输入边沿至少一个最坏传播延迟。
- 单独报告 SUM 和 COUT 最坏延迟。
- 顶层与子单元的 DRC/LVS 都 PASS。

## H. 双栅/HZO 扩展

### 物理方向检查

- 增加 n-TFT 有效正栅压不应导致开态电流下降（除非显式加入非单调物理）。
- 关闭铁电极化时应回到双栅静电基线。
- 将铁电系数设为零时不得仍然存在回滞。
- 很慢扫描和很快扫描的趋势应与动态模型假设一致。

### 数值检查

- 无 NaN/Inf。
- 不依赖不合理的极小时间步才收敛。
- 在相同激励下重跑结果一致。
- 初始极化状态与写入激励明确。

## I. 分章写作与单文件 HTML 报告

- `report/manifest.json` 严格列出老师要求的 12 个主章节和附录 A-E。
- 每章、每个附录独立维护，片段 ID、文件和清单一一对应。
- 自动目录顺序与清单一致，打印时每章另起一页。
- UTF-8，断网和移动目录后可独立打开。
- 全部 `img src` 为 `data:image/...;base64,...`，外部图片数为 0。
- 无外部 CSS、外部脚本和网络 CDN。
- 所有图片有图号、图题、`alt`、坐标单位和数据来源。
- 正式构建时 `[待填写...]` 数为 0。
- 关键数据在 HTML 表格和提交 CSV 中均可找到。
- `report/evidence_matrix.csv` 能把结论追溯到数据、脚本和命令。
- `make report-check` 必须在允许草稿占位符时通过。

## 项目总验收命令

最终应提供类似以下命令：

```bash
make clean-results
make all
make tcad-smoke
make report-check
make verify
```

`make verify` 必须以非零退出码表示任一必做项失败，不得只打印警告后继续返回成功。
