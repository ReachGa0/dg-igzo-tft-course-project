# 基础知识速查

## 1. 器件结构

基础器件是底栅、顶接触 IGZO TFT：Al 底栅、Al2O3 介质、IGZO 沟道和 Ti 源漏。双栅研究在沟道上方增加教学顶栅/介质，不能写成原始工艺已经制造。

## 2. n 型 IGZO

- 正的有效栅压通常增强电子沟道。
- `VGS=VG-VS`，`VDS=VD-VS`。
- `W/L` 增大通常提高电流尺度，也增加电容和面积。

## 3. 核心曲线

- `Id-Vg`：提取 VTH、SS、Ion/Ioff 和 gm。
- `Id-Vd`：检查线性区、饱和、输出电导和接触限制。
- 同一转移数据需要线性轴和对数轴。

## 4. 双栅

简化等效栅压：

```text
Veff = alpha_bottom * Vbottom + alpha_top * Vtop
```

`alpha` 由几何、电容、陷阱和沟道电荷共同影响。静电基准中的 0.5/0.5 只适用于当前对称无电荷教学结构。

## 5. 有源负载逻辑

- 负载 IGZO TFT 负责上拉，第二栅调节等效阈值。
- 驱动 IGZO TFT 网络负责下拉。
- 这是有比例逻辑，需要同时检查 VOH、VOL、VM、噪声裕量、静态功耗和延迟。
- 不能套用理想互补逻辑的零静态功耗结论。

## 6. DRC/LVS

- DRC 检查几何规则，不证明电路连接正确。
- LVS 从 GDS 提取器件和网络，再与参考网表比较。
- 正常 PASS 之外还必须有故障注入 FAIL。

## 7. 证据边界

- 静电模型不能给出漏电流。
- 行为模型不是 Level 15 方程。
- 教学 PDK 不是代工厂签核。
