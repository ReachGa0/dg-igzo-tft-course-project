# 二维 TCAD 实施路线

> 目标：在普通笔记本上建立从二维器件物理到 SPICE 紧凑模型的可复现桥梁。  
> 工具：DEVSIM 2.10.0 + Python；Gmsh 用于后续非矩形或局部加密网格。  
> 当前可运行层次：双栅静电 Poisson 基准、已关闭数值阶段门的单栅 IGZO T01 教学漂移扩散模型，以及包含极限回归、非零偏压、上下栅双向曲线、受限提取和二维状态的完整 T02 教学模型。
> 尚未完成层次：陷阱、非理想接触、几何/介质、温度、实验标定和参数不确定度模型，以及紧凑模型与电路传递。

## 1. TCAD 在整个项目中的位置

```text
材料/工艺参数
  -> 2D TCAD：空间电势、载流子、场和电流
  -> Id-Vg / Id-Vd 与内部状态
  -> 紧凑模型参数提取
  -> SPICE 电路
  -> PDK、版图、DRC/LVS
```

TCAD 解决“器件内部为什么这样变化”，SPICE 解决“很多器件组成电路后怎样工作”。二者不能互相替代：

| 工具层 | 主要输入 | 主要输出 | 本项目用途 |
|---|---|---|---|
| 2D TCAD | 几何、材料、边界、陷阱、接触、网格 | 电势、载流子、场、电流、I-V | 解释双栅耦合和参数趋势 |
| 紧凑模型 | 端口 I-V/C-V 或 TCAD/实测数据 | 快速端口方程 | 参数化单栅/双栅 IGZO |
| SPICE | 紧凑模型、网表、激励和负载 | VTC、波形、延迟、功耗 | 反相器、环振、全加器 |

## 2. 为什么先做静电，再做电流

完整 TFT 同时包含：

1. Poisson 方程；
2. 电子/空穴连续性；
3. 漂移扩散电流；
4. 态密度与陷阱占据；
5. 接触注入；
6. 可能的复合、温度和场依赖迁移率。

如果完整模型不收敛，很难知道是网格、边界、符号、材料还是输运方程出错。静电基准先验证几何与电势方向，故障范围会小很多。

## 3. T00：二维双栅静电基准

### 3.1 结构

```text
top gate contact
30 nm Al2O3 top dielectric（教学双栅假设）
24 nm IGZO channel
30 nm Al2O3 bottom dielectric（课程物理工艺）
bottom gate contact

IGZO 左端 = source，右端 = drain
横向长度 = 10 um
```

当前顶栅/顶介质是为双栅研究添加的教学结构，不是老师给出的单底栅工艺已经制造出的层。

### 3.2 方程

无自由电荷时：

```text
div(epsilon * grad(phi)) = 0
```

- `phi`：电势，单位 V；
- `epsilon`：区域介电常数；
- `grad(phi)`：空间电势梯度；
- `-grad(phi)`：电场。

此处不含载流子电荷，所以严格说是 Laplace 静电基准。保留“Poisson 求解框架”是因为后续会在右端加入电荷项。

### 3.3 边界

| 边界 | 类型 | 当前值 |
|---|---|---:|
| source | Dirichlet | 0 V |
| drain | Dirichlet | 0.1 V |
| bottom gate | Dirichlet | 0 V |
| top gate | Dirichlet | 1 V（基准图） |
| 其余外边界 | 自然边界 | 零法向通量 |
| 介质/IGZO 界面 | 连续条件 | 电势连续 |

### 3.4 网格

配置文件定义 `coarse` 和 `fine` 两档网格。必须比较相同偏压下的中心沟道电势，而不是只说“网格更密图更好看”。

通过判据：

```text
abs(phi_center,fine - phi_center,coarse) <= 5 mV
```

该阈值是本项目的数值验收阈值，不是材料物理常数。

### 3.5 栅耦合

分别扫描顶栅和底栅：

```text
-2, -1, 0, 1, 2 V
```

另一栅固定为 0 V，源/漏固定。对中心沟道电势做线性斜率：

```text
alpha_top = d(phi_center) / d(V_top)
alpha_bottom = d(phi_center) / d(V_bottom)
```

对称介质和几何下，二者应接近；改变一侧厚度或介电常数后，电容更强的一侧耦合应更大。这是后续双栅阈值模型的最小物理检查。

### 3.7 T00 能证明什么

- DEVSIM 环境能运行；
- 二维几何、区域、接触和界面已建立；
- 上下栅电势调控方向合理；

## 4. T01：单栅 IGZO 漂移扩散基线

### 4.1 要增加的方程

Poisson：

```text
div(epsilon * grad(phi)) = -rho
```

电子连续性稳态：

```text
div(Jn) = q * (R - G)
```

漂移扩散电流：

```text
Jn = q * mu_n * n * E + q * D_n * grad(n)
```

- `rho`：空间电荷密度；
- `Jn`：电子电流密度；
- `mu_n`：电子迁移率；
- `n`：电子浓度；
- `D_n`：扩散系数；
- `R/G`：复合/产生率。

### 4.2 求解顺序

```text
网格建立
  -> 零偏压 Poisson
  -> 平衡态载流子
  -> 小 VDS
  -> 小步增加 VGS
  -> 用上一点作下一点初值
  -> 保存收敛日志
```

不能直接从所有节点零初值跳到最大栅压和漏压，再把不收敛归因于软件。

### 4.3 最低输出

- `Id-Vg` 线性图与对数图；
- 多个 `Vg` 下 `Id-Vd`；
- 关态、阈值附近、开态的二维电势；
- 同三状态的电子浓度与电流密度；
- 两档网格对 VTH/SS/Ion 的影响；
- 电流守恒或端口电流差；
- 求解失败点。

| 零第二栅回程 | 2 族，共 62 点 | 最大正反向电流相对差 `8.19e-11` |
| DC 求解 | 318/318 收敛 | 包含各族独立初始化与偏压阶梯 |
| 端口守恒 | 最大相对不平衡 `3.72e-8` | 低于 `1e-5` 合同阈值 |
| 恒流 VTH 代理 | `0.520814/0.263857/-0.040395 V` | 对应第二栅 `-0.3/0/+0.3 V`，上下栅一致 |
| 耦合斜率代理 | `-0.93535 V/V`，`R2=0.99764` | OLS 只描述三点离散数值趋势，不等于物理电容比 |
| 上下栅互易性 | 最大电流相对差 `3.70e-8` | 只适用于对称教学顶/底栈 |
| 内部状态 | 6 个状态，14514 节点行、3564 沟道单元行、36 个 VTK | 覆盖双负、非对称、阈值附近和双正偏压 |

该 PASS 关闭完整 T02 教学模型数值门。正反向近乎重合源于当前无陷阱、无动态极化的路径无关方程，不能称为真实器件无回滞；VTH、`Delta VTH`、gm 和耦合斜率也不能称为实验参数。下一阶段 T03 必须先选一个最小单变量组、冻结输入与门槛，再运行该组，不能同时铺开五组参数。

## 6. T03：高难度项目的五组参数

## 7. TCAD 到 SPICE 怎样传参数

推荐传递的是可观测端口特征，而不是直接把 TCAD 每个内部参数同名填进 Level61：

| TCAD/实测特征 | 紧凑模型约束 |
|---|---|
| 低 VDS 的 `Id-Vg` | VTH、gm、迁移率尺度、SS |
| 多 VGS 的 `Id-Vd` | 线性区、饱和、输出电导、Rc |
| 上/下栅扫描 | 双栅耦合系数和阈值位移 |
| 小信号/瞬态或几何电容 | Cgs/Cgd/栅电容 |
| 温度曲线 | 温度系数 |

参数提取后必须回到未参与拟合的 TCAD/实测曲线做 holdout，不可只看训练曲线。

## 8. 笔记本算力控制

1. 先做二维，不做三维；
2. 先做矩形结构和局部网格加密；
3. DC 扫描先粗后细；
4. 只在阈值附近减小步长；
5. 单因素扫描并行前先保证单案例稳定；
6. 每个案例记录节点数、单元数、迭代/运行时间；
7. 动态铁电和 Monte Carlo 放到基础模型通过之后。

推荐单案例目标是秒级到数分钟，整组扫描在一晚内完成。若一个基础 DC 点就需要数小时，应先查网格和方程设置，而不是继续扩大扫描。
