# 架构确认汇报稿

## 30 秒版本

我的题目是“基于双栅 IGZO TFT 的二维器件模型、紧凑模型与可编程单极性逻辑教学 PDK”。项目先用二维 TCAD研究双栅、陷阱、接触、几何和温度，再把端口特征传到 AIM-Spice Level 15 与 ngspice 模型，最后用双栅 IGZO 有源负载完成基础门、环振、全加器及 KLayout DRC/LVS。S00、完整 T01 数值门、T02-A 顶栅极限回归和 T02-B 最小正向顶栅族已完成；当前已证明固定底栅时四个非负顶栅点的电流和内部状态同向增加，但尚未完成双向曲线族或阈值/跨导提取，也不会把数值响应冒充实验拟合或物理器件参数。

## 创新点

第二栅不只作为器件扫描变量，还用于调节 IGZO 有源负载阈值，把器件物理直接传到单极性逻辑的摆幅、功耗、延迟和频率。
