# 架构确认汇报稿

## 30 秒版本

我的题目是“基于双栅 IGZO TFT 的二维器件模型、紧凑模型与可编程单极性逻辑教学 PDK”。项目先用二维 TCAD研究双栅、陷阱、接触、几何和温度，再把端口特征传到 AIM-Spice Level 15 与 ngspice 模型，最后用双栅 IGZO 有源负载完成基础门、环振、全加器及 KLayout DRC/LVS。当前只冻结了架构，新的模型和电路尚未开始，不会拿旧结果充当新结果。

## 现有基础

- 课程给出 IGZO 工艺、尺寸和两组不同口径电学指标。
- DEVSIM 二维双栅静电基准已运行，但不含电流。
- 有 IGZO 单管 SPICE/GDS 外部基线可参考。
- 有 13 篇 HZO/ZrO2 文献和学长资料审计。
- 有 12 章单文件 HTML 报告框架。

## 完整路线

```text
数据冻结 -> T01 漂移扩散 -> T02 双栅 -> T03 五组参数
-> M00/M01 紧凑模型 -> C00 反相器
-> 基础门/环振/全加器 -> PCell/GDS -> DRC/LVS -> 报告
```

## 创新点

第二栅不只作为器件扫描变量，还用于调节 IGZO 有源负载阈值，把器件物理直接传到单极性逻辑的摆幅、功耗、延迟和频率。

## 必须请老师确认

1. 主 IGZO 原始 Id-Vg/Id-Vd 数据和批次。
2. 是否接受 DEVSIM 二维器件仿真。
3. 无双栅实测时是否接受文献约束敏感性。
4. 是否接受双栅 IGZO 有源负载作为电路验证。
5. 是否接受 KLayout 几何 LVS。
6. HZO 是否只作可选扩展。

## 主动说明的边界

当前只是架构冻结；静电基准不预测漏电流，行为模型不是原生 Level 61，教学 DRC/LVS 不是流片签核。
