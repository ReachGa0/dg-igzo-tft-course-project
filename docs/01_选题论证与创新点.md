# 选题论证与创新点

## 正式题目

**基于双栅 IGZO TFT 的二维器件模型、紧凑模型与可编程单极性逻辑教学 PDK**

## 选题依据

1. 直接对应老师的高难方向“双栅氧化物薄膜晶体管模型”。
2. IGZO 工艺、尺寸和部分电学指标已有来源，二维静电基准已可运行。
3. 可形成器件 -> 紧凑模型 -> 电路 -> PDK -> DRC/LVS 的完整参数链。
4. 单材料范围适合普通笔记本和课程周期。
5. HZO 文献可支撑可编程顶栅扩展，但不影响基础交付。

## 核心科学与工程问题

- 双栅电容耦合如何决定沟道势和阈值移动？
- 陷阱、接触和迁移率效应怎样区分？
- 端口特征如何进入 Level 15/ngspice 模型？
- 第二栅阈值调节能否构成可用的 IGZO 有源负载逻辑？
- GDS 几何能否独立提取器件和网络并完成故障注入 LVS？

## 创新点

1. **二维内部状态到端口模型**：不仅拟合曲线，还解释电势、载流子和场分布。
2. **双轨紧凑模型**：同一数据目标约束 AIM-Spice Level 15 和 ngspice 行为模型。
3. **双栅有源负载逻辑**：把第二栅调阈值从器件变量变成电路设计变量。
4. **几何 LVS 与故障注入**：从 GDS 提取，不比较两份同源手写网表。
5. **可审计交付**：每张图和每个结论都能回到数据、脚本、命令和证据等级。

## 为什么不选其他高难方向

- CFET/OISC 需要新工艺、新器件和新架构同时导入，当前资料匹配度低。
- Cogenda Te TFT 缺少 Te 原始数据和已验证工程。
- 纯 HZO 材料项目与现有 IGZO 器件/PDK 主线脱节，适合作为扩展而非主线。

## 答辩亮点

- 双栅偏压引起的 Delta VTH 和二维沟道状态。
- 一个 INV 从模型、网表、GDS、DRC 到几何 LVS 的最小闭环。
- 有源负载偏压对摆幅、功耗、延迟和环振频率的定量影响。
- 正常版图 PASS、故意断路/短路 FAIL、修复后重新 PASS。
- 清楚区分实测、TCAD、模型预测和教学规则。
