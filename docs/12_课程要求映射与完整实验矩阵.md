# 课程要求映射与完整实验矩阵

> 权威要求文件：`实验课程项目与报告要求(1).html`  
> 最终格式：单个可独立打开的 HTML，全部图片嵌入，不依赖网络和绝对路径。  
> 写作方式：12 章和附录分别维护，按清单自动组装；打印时每章另起一页。
> 本项目定位：高难度“精确双栅氧化物 TFT 模型”的分层实现，加上完整 SPICE/PDK/逻辑电路闭环。

## 2. 完整项目流程

```text
R0 需求冻结
  -> R1 数据审计与来源哈希
  -> R2 2D TCAD 静电基准
  -> R3 2D IGZO 漂移扩散与五组参数
  -> R4 IGZO 紧凑模型标定
  -> R5 INV/NAND/NOR/XOR 前仿真
  -> R6 PCell/GDS/DRC/LVS
  -> R7 五级环振与一位全加器
  -> R8 双栅紧凑模型与可选 HZO
  -> R9 分章写作、单文件 HTML 报告与工程验收
```

每一级输出都成为下一级输入，不能跳过数据血缘。

## 4. 五组参数怎样满足高难度要求

老师建议高难度项目不少于五组参数。本项目器件主线固定为：

1. 双栅偏压与电容耦合；
2. 体/界面陷阱；
3. 接触电阻或势垒；
4. 沟道/介质几何；
5. 温度。

电路中的 Wp/Wn、VDD、Cload 是额外分析，不拿它们替代器件主线的五组物理参数。HZO 是可选扩展，也不计入基础五组以降低风险。

## 5. 最终报告严格按 12 章分别写作

每章使用独立 XHTML 片段，文件顺序由 `report/manifest.json` 固定。附录 A-E 同样拆分。构建器自动生成目录并组装为最终单文件，禁止在章节源和最终 HTML 中维护两套正文。

### 1. 项目名称与基本信息

姓名、学号、班级、教师、日期、工具和版本。未填写个人信息前报告不得标为最终版。

### 2. 摘要

300 至 500 字，按问题、方法、定量结果、结论/边界四段逻辑写。没有跑出的结果不得用将来时伪装成已完成。

### 3. 研究背景与项目目标

说明双栅调控、IGZO 有源负载逻辑、紧凑模型与 PDK 的关系，列出可检验问题。

### 4. 理论基础与模型原理

写 Poisson/漂移扩散、TFT 指标、Level15/行为模型、双栅耦合和电路原理，并逐一解释符号单位。

### 5. 仿真工具与模型建立

写 DEVSIM 结构/网格/边界/求解，AIM-Spice/ngspice 设置，KLayout 层/DRC/LVS 流程。

### 6. 参数设置与来源

一张主表至少有：名称、符号、值、单位、来源类型、来源文件/文献、用途、是否拟合。

### 7. 基准仿真结果

先单管和 TCAD，再反相器。每个图有输入条件、单位和原始 CSV。

### 8. 参数分析与讨论

按五组器件参数展开；每组至少三点，统一坐标，给数值变化和机制解释。

### 9. 模型验证或结果对比

与实验、条件完整文献、学长参考或另一工具比较。必须把“参考导入”与“精确验证”分开。

### 10. 电路或系统设计结果

INV/基础门/环振/全加器，给原理图、激励、负载、真值表、延迟、功耗、版图和验证。

### 11. 结论

只列有数值和文件证据的结论，同时写局限。

### 12. 参考文献

正文引用与列表对应，软件手册、老师数据、学长资料和论文来源分清。

附录 A-E 继续包含参数、原始数据、代码、补充/失败结果和运行说明。

## 6. 分章源与单文件 HTML 验收

最终 `report/final/实验报告.html` 必须满足：

- UTF-8；
- 可断网打开；
- CSS 在文件内；
- 图片是 `data:image/...;base64,...`；
- 没有 `C:\...`、`/mnt/c/...`、`http://...` 或 `https://...` 图片；
- 关键数据以 HTML 表格出现，不只是一张截图；
- 12 个章节齐全；
- 附录有运行命令和文件索引。
- 章节/附录源文件 ID 与清单一致且顺序唯一；
- 打印样式保证每章另起一页。

章节工作稿允许用 `assets/...` 引用 `report/assets/` 中的本地图片，`make report` 负责组装和嵌入；提交时只交最终单文件和完整工程包。

## 8. 完成顺序与降级

### 必须先完成

1. 数据口径；
2. T00/T01 或明确降级的 TCAD 结果；
3. 单管紧凑模型；
4. 反相器；
5. 基础门；
6. INV 的 GDS/DRC/LVS 最小闭环；
7. 环振和全加器；
8. 报告重建。

### 时间不足时

- 保留 T00 和一个收敛的 T01 基准，减少 TCAD 参数点，但五组至少给单因素趋势；
- HZO/NLS 首先降级；
- 不降级数据来源、误差、DRC/LVS 故障注入和单文件 HTML；
- 不能用更多截图掩盖缺少输入文件。
