# 文献调研矩阵

## 先说结论

本地 13 篇论文不是 IGZO TFT 模型参数提取论文，而是一组高度集中的 HfO2/HZO/ZrO2 铁电/反铁电文献。它们能支持本项目的 HZO 顶栅、静态回滞、NLS 开关动力学、唤醒/疲劳和应变敏感性，但不能取代 IGZO 的实测 Id-Vg/Id-Vd。

## 论文到模型的对应

| 模型层 | 需要的数据 | 论文支持 | 本项目可以做的结论 |
|---|---|---|---|
| 单栅 TFT I-V | IGZO Id-Vg、Id-Vd | 这组论文不提供 | 必须用老师数据 |
| 双栅静电耦合 | 上/下栅扫描曲线、介质厚度/k | 文献只提供一般背景 | 无双栅数据时只做敏感性 |
| 铁电静态回滞 | P-E 回线、Pr、Ec、厚度 | #1、#4、#9、#12、#13 | 可做文献约束模型 |
| NLS 动态 | 脉冲宽度/电场与已翻转极化 | #1、#8、#11 | 有可数字化数据才能拟合 |
| 唤醒/疲劳 | 循环次数与 P-E/窗口 | #3、#7、#8、#13 | 先做参数敏感性，不假装寿命预测 |

## 建议精读顺序

1. #1 综述：建立全局语言和证据边界。
2. #11 NLS：理解为什么需要翻转时间分布。
3. #8 域开关动力学：理解局部开关场非均匀性。
4. #13 应变/界面：理解不能把所有唤醒归因于单一参数。
5. #7 可靠性：给报告的限制与展望章提供依据。

## 读论文时每篇必填的七项

1. 研究对象的材料、厚度、电极和热处理。
2. 测量结构是电容、FeFET、FTJ 还是其他器件。
3. 自变量和控制变量。
4. 直接测量量与由模型推断的量。
5. 能进入本项目的参数、方程或趋势。
6. 不能外推的边界。
7. 可用于 PPT 的一句话和对应图号。
